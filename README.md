# Local-Manifest-Nashc (Realme 8)
=========================================

Assuming already synced Sources (A15):
 - cd into your ROM's folder
 
```
curl https://raw.githubusercontent.com/Realme-Nashc-Mtk/Local-Manifest/refs/heads/15.0/clone.sh | bash
```

- Apply Gatekeeper hal patches :
```
curl https://raw.githubusercontent.com/Realme-Nashc-Mtk/Local-Manifest/refs/heads/15.0/patch.sh | bash
```
